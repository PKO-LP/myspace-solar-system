# Ручные проверки MySpace

**Состояние:** проверки ещё не проводились; код приложения не реализован.

Для каждого сценария запишите: дата → среда → действия → ожидаемый результат → фактический результат → пройдено/не пройдено.

1. Запуск — видны Солнце и восемь планет с изображениями.
2. Выбор каждой планеты мышью — выделяется нужный объект, открывается соответствующая карточка, камера удерживает его в центре.
3. Выбор каждой планеты кнопкой — результат совпадает с выбором в сцене.
4. Приближение и отдаление до предела — камера не попадает внутрь объекта; система остаётся доступной для просмотра.
5. Поворот — обзор поворачивается вокруг текущего центра.
6. Пауза — планеты останавливаются; камера, выбор планет и карточки работают.
7. Скорости ×0,5, ×1, ×5, ×10 — движение меняется; текущий множитель виден.
8. Общий вид — камера возвращается, карточка закрывается, выделение снимается.
9. Отсутствующая текстура — используется заглушка, приложение не закрывается.
10. Интерфейс 1280 × 720 — текст читается, карточки не обрезаются; элементы интерфейса не пропускают нажатия к планетам.
11. Общий обзор — измерить частоту кадров и записать характеристики ПК.
12. Работа 10 минут — нет аварийного завершения.
13. Другой компьютер — установка и запуск только по README, без помощи автора.
